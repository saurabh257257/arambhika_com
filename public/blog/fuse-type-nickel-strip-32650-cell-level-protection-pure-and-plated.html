Nickel Strip

Fuse-Type Nickel Strip for 32650

A built-in weak link for each cell

By Arambhika · 7 November 2026 · 5 min read

In a parallel group, one shorted cell can dump the current of its neighbours into a fault. A fuse-type strip is a way to isolate that cell.

How it works

The strip has a narrowed section on the path to each cell. In normal use it carries the cell's current easily. If a cell goes into a short, the surge heats the narrow part until it opens, disconnecting that cell from the group.

The options

  • Plated 2P(32650) 36.5x0.15 mm fuse type
  • Pure 2P(32650) 36.5x0.15 mm fuse type

What it does not do

  • It does not replace the BMS or the main fuse.
  • It does not stop an external short; that is the main fuse's job.
  • It does not protect against over-charge or over-discharge.

Using it well

Choose a fuse strip whose narrow section carries the per-cell normal current with margin. Keep welds consistent so the narrow part, not the weld, is the weak point. Read the strip type guide and the 32140 guide.

General guidance only. Check cell, BMS and strip datasheets and the standards that apply to your product before you build or sell a pack.
